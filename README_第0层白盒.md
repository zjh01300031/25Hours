# 第0层 · 避难所 1 区（白盒）

《第25小时》的横向 2D 白盒：1F（右上）+ 地下 B1（左下）+ 中间楼梯井，带 6 个碎片收集、2 个可对话人偶、1 个进事件的「回声匣」、1 个未解锁的 2 区门。

所有内容都由编辑器脚本生成，**没有用视频里的素材**：图是代码画的占位 PNG（`Assets/Art`），中文用本机黑体。

---

## 一、怎么打开

**第一次 / 想重铺一遍**：菜单 `工具 → 25小时 → 重建第0层（白盒）`

**手动微调的工具箱**：菜单 `工具 → 25小时 → 白盒工具箱`（重建 / 只截图 / 打开两个场景 / 选中物体对齐网格 / 在选中位置加一块可站立平台）

生成的东西：

| 路径 | 内容 |
| --- | --- |
| `Assets/Scenes/Shelter_L0.unity` | 第 0 层主场景 |
| `Assets/Scenes/Event_01.unity` | 事件一 · 回声室（棋盘玩法占位） |
| `Assets/Scenes/Event_02.unity` | 事件二 · 深处（完成事件一才解锁） |
| `Assets/Art/*.png` | 全部占位图（16px/单位，Point 过滤） |
| `Assets/Fonts/SimHei.ttf` | 从 `C:\Windows\Fonts\simhei.ttf` 复制的字体 |
| `Assets/Editor/WhiteBox*.cs`、`Level0Builder.cs` | 生成器本体 |

**直接玩**：菜单 `工具 → 25小时 → 打开第0层并运行`

**截世界预览图**（不带 UI）：菜单 `工具 → 25小时 → 截图预览（世界）`，输出到 `D:\Unity2D\Build\25Hours\预览\`

**打包 exe**：菜单 `工具 → 25小时 → 构建 Windows 试玩版`，输出 `D:\Unity2D\Build\25Hours\25Hours.exe`

**一步到位**（重建场景 + 截预览 + 打包）：菜单 `工具 → 25小时 → 一键：重建 + 截图 + 打包`

命令行（和菜单等价）：

```
"D:\Unity2D\_install\2022.3.62f3c1\Editor\Unity.exe" -batchmode -quit ^
  -projectPath "D:\Unity2D\Projects\25Hours" ^
  -executeMethod Level0Builder.BuildAll ^
  -logFile "D:\Unity2D\Build\25Hours\build.log"
```

## 二、操作

| 键 | 作用 |
| --- | --- |
| `A` / `D` 或 `←` / `→` | 左右移动 |
| `空格` | 跳（有 0.08s 土狼时间 + 0.1s 跳跃缓冲） |
| `E` | 和最近的发光物体交互 / 推进对话 |
| `Esc` | 关对话；在事件场景里直接回第 0 层 |

上楼梯：台阶只是「看起来是台阶」，真正站的是里面一条**看不见的斜坡碰撞体**（`01_建筑/楼梯/楼梯_斜坡碰撞`，从 (2,0) 斜到 (-3,-8)）。玩家在斜坡上锁重力、按坡面方向走，所以上下都顺，不会卡在台阶缝里。要改坡度就改这个物体的位置/旋转/长度。

### 分层（第二次白盒迭代加的）

| 组 | 内容 | 说明 |
| --- | --- | --- |
| `01_建筑` | 地板、墙、楼梯 | 只有这些是实心碰撞 |
| `02_家具` | 展柜台座、桌子、工作台、管道 | 纯装饰 |
| `03_可交互` | 碎片、对话物、两扇门 | 9 层，Trigger |
| `05_灯光` | 顶灯、吊灯、事件后的光晕 | |
| `07_细节` | 墙裙、墙筋、横梁、挂钟、光池、门框、B1 杂物 | 不碰撞，用来读空间、做路标 |
| `08_前景` | 顶梁、右框、悬线 | sortingOrder 30，压在镜头与角色之间，做纵深 |

挂钟停在「第 25 小时」（1 点位置），是 1F 的视觉路标，也是主题提示。要换位置直接改 `Level0Builder.BuildDetail` 里 `Box(parent, "挂钟", 11.6f, 6.05f, ...)`。
## 三、场景结构

```
Shelter_L0
├── GameProgress          跨场景进度（单例，6 个碎片 / 事件是否完成）
├── Main Camera           正交 size 4.6，挂 CameraRig2D 跟随玩家并夹范围 x[-8,10.2] y[-6.4,2.6]
├── World
│   ├── 01_建筑           地板 / 天花板 / 左右墙 / 楼梯 / 背景（都带 BoxCollider2D）
│   ├── 02_家具           展柜台座、桌子、吊架、工作台、床垫、2 区暗角（不带碰撞）
│   ├── 03_可交互         碎片 / 人偶 / 展柜 / 回声匣 / 2 区门（Trigger，不挡路）
│   ├── 04_角色           玩家_主控（红块，Rigidbody2D + BoxCollider2D）
│   ├── 05_灯光           1F 顶灯 + 光晕、B1 吊灯
│   ├── 06_系统           事件登记表（EventCatalog）+ 自测脚本
│   └── 场景状态          ShelterState：事件后亮光 / 多一个人偶 / 墙面色温
├── UI                    Canvas 1920×1080（标题、碎片计数、提示条、对话框、toast）
└── EventSystem
```

Layer 约定：`Ground = 8`（可站立的实体），`Interactable = 9`（可交互物）。玩家用 `OverlapCircle(radius=1.9)` 找最近的可交互物。

事件入口：**两扇门**——1F 东墙 `门·事件一`（一开局就能进）、楼梯下暗角 `门·事件二`（`requiresEventId = event_01`，完成事件一才解锁，门片和门口光会自己换色）。

进门 → `World/06_系统/事件登记表（EventCatalog）` 里查 id 对应的场景 → 进事件场景。事件场景只要挂一个继承 `EventRoomBase` 的脚本，做完调 `Complete()` 就会记录完成并回第 0 层（墙变暖、顶灯亮、展柜多一个人偶、人偶换台词）。**棋盘和玩法是别人的任务**，详细接入方式见 [README_事件接入.md](README_事件接入.md)。

## 五、怎么自测（不用人守着）

打包出来的 exe 支持一个 `-selftest` 参数：自动走下楼梯 → 看回声匣（只对话）→ 试锁着的事件二门 → 进事件一（调 `Complete()`）→ 事件二门解锁 → 进事件二 → 回到 1F，沿途截图并写日志，然后自己退出。

```
"D:\Unity2D\Build\25Hours\25Hours.exe" -selftest -screen-width 1280 -screen-height 720 -screen-fullscreen 0
```

- 截图：`D:\Unity2D\Build\25Hours\selftest\01_出生.png` … `15_展柜两个人偶.png`（含事件二锁着 / 解锁对比）
- 日志：`%USERPROFILE%\AppData\LocalLow\Zhao\第25小时\Player.log`（中文可能是乱码，内容仍可读）

改了场景后想快速确认「还能不能走通」，跑这个比手动玩快。脚本在 `Assets/Scripts/ShelterSelfTest.cs`，只有命令行带 `-selftest` 才会运行，正常玩不受影响。

## 六、怎么微调（不改代码）

生成出来全是普通 GameObject，可以直接在 Scene 里：

- 拖动位置 / 改 `SpriteRenderer` 尺寸 / 改 `BoxCollider2D` 大小
- 改 `DialogueProp.lines`、`FragmentPickup.lines` 的文案（Inspector 里直接编辑数组）
- 加平台：复制一个 `01_建筑` 下的地板，改位置和尺寸即可（它带碰撞）；或者用 `白盒工具箱` 的「加一块可站立平台」（只有碰撞、没有外观）
- 对齐：`白盒工具箱` 的「把选中物体对齐到网格」（0.25）
- 换美术：把 `Assets/Art` 里的同名 PNG 覆盖成你的图，场景不用动（保持 Point / 16 PPU 即可）

⚠️ 再点一次「重建第0层」会**覆盖**场景里手工改的东西。想保住手工修改，建议：改完把 `Shelter_L0` 另存一份（`Ctrl+Shift+S`），或者把要复用的东西拖成 Prefab。

## 七、已知限制 / 下一步

- 美术全是纯色块占位，没有动画、没有音效。
- 事件场景只有一个空模板（`Event_Template`），棋盘 / 顶视角地图是事件负责人的部分，接入约定见 `README_事件接入.md`。
- 没有存档：进度只在 `GameProgress` 单例里，退出即丢。
- 楼梯是视觉台阶 + 隐形斜坡两套：改台阶样子不影响走路，但改斜坡要同时改台阶位置才不穿帮。
- 2 区（B1 右侧那扇门）按设计图留了「未解锁」状态，门后没有内容。
- 字体 `SimHei.ttf` 是从 Windows 复制的，**只适合本机测试**；要发布请换成可商用开源字体（思源黑体 / 霞鹜文楷等），并在 `WhiteBoxArt.FontAssetPath` 改路径后重建。
- 玩家目前是红块，没有朝向翻转（`ShelterPlayer` 里预留了 `spriteRenderer` 字段）。
